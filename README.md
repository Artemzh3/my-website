# 🌐 Интерактивный современный веб-сайт

Быстрый, адаптивный веб-сайт с богатой пользовательской логикой, созданный на чистом **HTML5**, **CSS3** и **JavaScript** (Vanilla JS) без тяжелых сторонних фреймворков.

---

## 🎛️ Реализованная интерактивная логика

1. 💰 **Интерактивный калькулятор стоимости и сроков проекта**:
   - Выбор типа сайта (Лендинг, Корпоративный, Интернет-магазин, Веб-сервис) с динамическим пересчётом.
   - Ползунок (range-slider) количества страниц с моментальным обновлением цены и сроков.
   - Чекбоксы дополнительных опций (UI/UX дизайн, SEO-оптимизация, онлайн-оплата, срочный запуск).
   - Анимированный счётчик итоговой суммы и дней.
   - **Связка с формой контактов**: кнопка «Оформить заказ с этим расчетом» автоматически формирует подробный бриф, переносит его в текстовое поле формы ниже и плавно скроллит страницу к оформлению.

2. 🔍 **Живой поиск и динамическая фильтрация портфолио**:
   - Фильтрация по табам категорий (`Все`, `Лендинги`, `Веб-сервисы`, `Корпоративные`).
   - Живой поиск (по названию и описанию) с кнопкой быстрой очистки.
   - Сообщение «Ничего не найдено», если результаты отсутствуют.

3. ❤️ **Система лайков с сохранением в `LocalStorage`**:
   - На карточках проектов можно ставить и снимать лайки.
   - Количество и состояние сохраняются в браузере и не сбрасываются при обновлении страницы.

4. 🪟 **Интерактивное модальное окно деталей проекта**:
   - Клик по кнопке «Подробнее &rarr;» открывает модальное окно с описанием кейса, списком стека технологий и кнопкой быстрого заказа.
   - Закрытие по крестику, клику на фон или клавише `Esc`.

5. ⭐ **Интерактивный блок отзывов клиентов**:
   - Интерактивный пятизвёздочный выбор рейтинга.
   - Возможность опубликовать собственный отзыв, который мгновенно появляется в списке и сохраняется в `localStorage`.

6. 🌗 **Переключатель тем (Dark / Light mode)**:
   - Автоматически учитывает тему операционной системы.
   - Сохраняет выбор пользователя в `localStorage`.

7. 📱 **Адаптивное бургер-меню и ScrollSpy**:
   - Плавное выдвижение меню на смартфонах.
   - Автоматическая подсветка активного пункта навигации при скролле.

---

## 🚀 Как запустить

### Вариант 1. Напрямую в браузере
Просто откройте файл **`index.html`** двойным кликом мыши или перетащите его в окно браузера (Chrome, Safari, Firefox).

### Вариант 2. Локальный сервер
Выполните команду в терминале:
```bash
python3 -m http.server 8000
```
Затем перейдите по адресу: [http://localhost:8000](http://localhost:8000).

---

## 📁 Файловая структура

- **`index.html`** — разметка всех блоков и модального окна.
- **`style.css`** — стили, адаптивность, анимации и темы оформления.
- **`script.js`** — вся JavaScript-логика.
- **`README.md`** — документация проекта.
