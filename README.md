# 🌐 Интерактивный веб-сайт с отправкой писем на почту

Адаптивный, быстрый веб-сайт с онлайн-калькулятором стоимости, фильтрацией портфолио, системой лайков и **реальной бесплатной отправкой заявок на почту `metrazh2000@mail.ru`**.

---

## ✉️ Как работает отправка писем на `metrazh2000@mail.ru` (Бесплатно)

В форму интегрирован сервис **FormSubmit** (AJAX API).
- Это **на 100% бесплатно**, без скрытых лимитов или необходимости оплачивать сервер.
- **Первая отправка (Активация)**:
  1. Заполните форму на сайте (или нажмите кнопку «Оформить заказ с этим расчетом» в калькуляторе) и нажмите «Отправить сообщение».
  2. На почту `metrazh2000@mail.ru` придёт **однократное письмо** от FormSubmit с кнопкой **«Activate Form»**.
  3. Кликните по этой кнопке один раз, чтобы подтвердить владение почтовым ящиком.
  4. После этого **все последующие сообщения** с сайта будут мгновенно приходить прямо вам на `metrazh2000@mail.ru` с красивой таблицей данных!

## 🚀 Как залить сайт на сервер БЕСПЛАТНО (100% Free Hosting)

Вы можете опубликовать сайт в интернете буквально за 1 минуту без каких-либо затрат.

### Способ 1. Netlify Drop (Самый простой — без регистрации в консоли)
1. Откройте в браузере сайт: **[app.netlify.com/drop](https://app.netlify.com/drop)**
2. Просто **перетащите папку проекта `WebSite`** мышкой в выделенную область на странице.
3. Готово! Через 5 секунд сайт опубликован и вам будет выдана постоянная ссылка вида `https://ваше-имя.netlify.app` с бесплатным SSL-сертификатом (HTTPS).

---

### Способ 2. GitHub Pages (Идеально для хранения кода и хостинга)
1. Создайте бесплатный аккаунт на [github.com](https://github.com), если его еще нет.
2. Создайте новый репозиторий (например, `my-website`).
3. В терминале в папке сайта выполните:
   ```bash
   git remote add origin https://github.com/ВАШ_ЛОГИН/my-website.git
   git branch -M main
   git push -u origin main
   ```
4. В настройках репозитория на GitHub перейдите в **Settings &rarr; Pages**, в разделе **Branch** выберите `main` и нажмите **Save**.
5. Через 1-2 минуты сайт станет доступен по адресу: `https://ВАШ_ЛОГИН.github.io/my-website/`.

---

### Способ 3. Vercel
1. Перейдите на [vercel.com](https://vercel.com) и войдите (например, через GitHub или Email).
2. Нажмите «Add New Project» и выберите репозиторий или загрузите файлы проекта.
3. Нажмите «Deploy» — сайт мгновенно развернется на ультрабыстром мировом CDN.

## 📁 Файловая структура

- **`index.html`** — разметка сайта, калькулятора, модального окна и формы обратной связи с анти-спам защитой.
- **`style.css`** — стили, светлая/тёмная тема, адаптивная сетка под смартфоны и ПК.
- **`script.js`** — логика расчёта стоимости, фильтрация, лайки, отзывы и реальная отправка заявок через FormSubmit на `metrazh2000@mail.ru`.
- **`README.md`** — инструкция по хостингу и настройке.
